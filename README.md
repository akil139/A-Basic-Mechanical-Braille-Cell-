The goal of this project is to develop a basic mechanical braille cell prototype. Our design focuses on creating braille materials for various subjects using eco-friendly materials while promoting efficient use of space, legibility, and readability. The final design is evaluated for its effectiveness in promoting accessibility and inclusivity.

**The prototype utilizes a combination of hardware and software components to convert digital text into a tactile braille character.**


*Braille Cell:* A simple cardboard cell was used for the prototype to demonstrate the concept.

*Actuation Mechanism:* Stepper motors are used to raise and lower the pins, forming the braille characters.

*Control Electronics:* An FPGA board is used to translate digital input into signals for the actuation mechanism.

*Power Source:* A small battery or USB power supply powers the system.


The project was a collaborative effort, with team members handling different aspects of the design and implementation. This included finding logical expressions for ASCII to braille conversion using K-mapping, programming the FPGA, and assembling the hardware prototype.
